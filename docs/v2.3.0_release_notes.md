# PreCut v2.3.0 Release Notes

**Release Date:** November 16, 2026

---

## What's New

**Optional aria2c direct downloads** - faster HTTP/HTTPS transfers, now built in.

PreCut ships with `aria2c` 1.37.0 and exposes it as a Settings toggle: **Use aria2c for direct downloads** (off by default). When enabled, direct HTTP/HTTPS downloads use 16 connections and segments (`-x16 -s16 -k1M --file-allocation=none`), which is typically noticeably faster than yt-dlp's single-connection native downloader.

- HLS/DASH streams (for example the IGN Walkthrough downloader) always stay on yt-dlp's native downloaders, because aria2c cannot handle those manifests.
- Progress, speed, and size keep updating during aria2c downloads via a `.part` file monitor.
- **Cancel** and **Pause** terminate the aria2c process tree, so nothing keeps downloading in the background.
- If `aria2c.exe` is unavailable (a plain source checkout without `assets/bin/`), the toggle is disabled and PreCut falls back to the native downloader automatically.

**Licensing:** aria2 is GPLv2. The bundled binary, license text, and source link are documented in [THIRD_PARTY.md](../THIRD_PARTY.md).

---

## Upgrade Notes

- No settings migration required. `use_aria2c` is added with the default `false`, so behavior is unchanged until you turn the toggle on.
- Existing Clips, Proxy, OST, Walkthrough, and Transcript workflows are unchanged.
- FFmpeg must still be on `PATH` for stream remuxing/merging.

---

## Installation

1. Download `PreCut-2.3.0-portable.zip` from the release.
2. Extract it to a writable folder of your choice.
3. Run `PreCut.exe`.
