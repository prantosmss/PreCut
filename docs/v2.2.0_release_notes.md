# PreCut v2.2.0 Release Notes

**Release Date:** November 15, 2026

---

## What's New

**Walkthrough Downloader** - a dedicated page for IGN content.

Paste any IGN video or wiki page link (for example `https://www.ign.com/wikis/red-dead-redemption/Empty_Promises`). PreCut scans the page in the background and fills a **Video** selector with every walkthrough video it finds, using the real video titles. Pick the one you need, choose a quality, and download.

- Supports IGN video pages (`/videos/...`) and IGN wiki pages that embed videos.
- Quality selector: `Up to 1080p` (default), `720p`, `480p`, `360p`.
- Files are saved to your project's `Walkthrough/` folder as `<video title>.mp4`.
- The page remembers your last quality choice.
- Same safety rails as the other downloaders: project folder required, duplicate protection, and a maximum of 2 concurrent downloads.

**Why a custom IGN resolver?** yt-dlp's IGN extractor depends on an API that IGN retired, so it returns "Content not found" for current links. PreCut now reads IGN's Next.js page payload directly and pulls the real `master.m3u8` stream, and download cards can resolve links like this before handing the file to yt-dlp.

---

## Upgrade Notes

- No settings migration required. `walkthrough_quality` is added with the default `Up to 1080p`.
- Existing Clips, Proxy, OST and Transcript workflows are unchanged.
- FFmpeg must still be on `PATH` for stream remuxing/merging.

---

## Installation

1. Download `PreCut-2.2.0-portable.zip` from the release.
2. Extract it to a writable folder of your choice.
3. Run `PreCut.exe`.
